## Rgssd

A Cli tool to manipulate `rgssad` / `rgss2a` / `rgss3a` files.

### Usage
```
    rgssd       <commands>

Commands:
    help
    version
    list        <archive>
    unpack      <archive> <folder> [<filter>]
    pack        <folder> <archive> [<version>]
    repack      <folder> <archive> <template>
```
